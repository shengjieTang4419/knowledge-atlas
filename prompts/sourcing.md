# L2 检索层 · 找可信源（两层：平台 + 条目）

给定主题，产出相对可信的来源。可信 = 相对可信（分级见 `config/sources.yml`）。

**两层是硬要求**（2026-10-12 定）：

- **可信源 = 平台级**，要泛化、可跨主题复用：`GitHub`、`arXiv`、`Oracle 官方文档`、
  `MDN`、`Stack Overflow`、`JCP 规范库`……**不是**某个具体文件/论文/仓库。
  同一个平台只写一次；平台数由「站」的个数决定，不由你列了几篇文献决定。
- **条目 = 文件级**，挂到某个平台下：arXiv 上的哪篇论文、GitHub 上的哪个仓库、
  规范里的哪一节。条目依附主题，只对这个主题有意义。

```
给定学习主题，产出「平台 + 条目」两层清单。

主题：<topic>

产出：
1. sources[]（平台，≤5 条，按可信度降序）：
   - name：平台名（GitHub / arXiv / Oracle 官方文档 这种泛化出处，不要写成具体文件名）
   - type：规范 / 源码 / 书籍 / 论文 / 博客 / 社区
   - why：这个**平台**为什么可信（一句话，跨主题成立）
   - home：平台入口 URL（它决定平台的归一身份，必须给）
2. items[]（条目，每个平台 1~3 条）：
   - title：具体文件 / 页面 / 章节名
   - source：所属平台的 name（必须与上面 sources 里的完全一致）
   - locator：直接可读的 URL（或 ISBN+章节）
   - note：这条为什么值得读（一句话）

约束：
1. 优先官方规范与源码（最高可信度）。
2. 同一平台的多个条目不要重复列平台；平台数宁少勿多。
3. 博客/社区只作差分线索，不作知识本体。
4. 条目 ≤ 5 条，宁缺勿滥；给不出平台的条目不要输出。
```
