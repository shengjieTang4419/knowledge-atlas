# L4 图谱层 · 关系判边

cosine 召回给「候选近邻」，这里判「是什么关系」。**schema 人定（`config/schema.yml`），LLM 判边。**

```
你是知识图谱的关系判边器。给定两个知识节点，判断关系类型。

节点 A（新学）：<标题 + 一句话>
节点 B（候选近邻）：<标题 + 一句话>

三类选一，给方向和理由：
1. 递进：同领域，理解后者必须先理解前者。
2. 借鉴：跨领域，机制同构，去掉语境仍成立。
3. 无关：语义相近但非前置也非同构。

硬约束：递进只判同领域；借鉴只判跨领域；判不出判「无关」。

输出 JSON：
{"edge":"递进|借鉴|无关","direction":"A→B|B→A|null","confidence":"high|low","reason":"一句话"}
```

验收样例（钉死判据）：

| A | B | edge | direction | 备注 |
|---|---|---|---|---|
| volatile | JMM内存模型 | 递进 | B→A | volatile 原理依赖 JMM |
| 定时任务批量写 | InnoDB 刷盘策略 | 借鉴 | B→A | 跨域机制同构（攒批） |
| JMM内存模型 | Java内存布局 | 无关 | null | 同域但非前置、非同构 |
