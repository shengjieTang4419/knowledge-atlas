# L3 拓扑层 · 实体关系梳理

可信源内容 → 实体卡片 + 关系边（借鉴 Karpathy 的 LLM wiki 过程）。

```
从可信源内容中抽取实体和关系，建成知识卡片。

可信源内容：<markdown 片段>

产出：
1. 实体清单：每个给 {名称, 类型(概念/机制/产品/规范/人物), 一句话}
2. 关系：实体对之间的 {递进|借鉴, 方向}（schema 见 config/schema.yml）
3. 卡片：按固定模板输出 markdown 双链卡

约束：
- 实体对齐：同名/别名合并，不重复建卡。
- 只抽「骨架级」要点，不抄全文（深挖留给 Q&A）。
- 关系判不出就省略，不硬造边。
```

卡片模板（与 `data/wiki/notes/` 现有样例一致）：frontmatter(领域/类型) + 一句话 / 是什么 / 关系 / 挂载 / 待深挖。
