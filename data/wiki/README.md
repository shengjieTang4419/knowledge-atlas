# knowledge-atlas wiki（Obsidian 库）

这是「体系化知识平台」的 L2 实体层：markdown 双链 + 实体关系。git 仓为唯一真相源，Obsidian 只是阅读器。

## 约定
- **骨架先行**：每个领域先立 MOC（地图），再挂细节。概貌来自权威结构，不自下而上聚类。
- **双链即图**：用 `[[节点]]` 连接实体；同名实体只建一张卡（实体对齐）。
- **卡片模板**：一句话 / 是什么（骨架）/ 为什么重要 / 挂载（本地课件+相关节点）/ 待深挖。
- **Raw 不进本库**：抓取/课件原始材料放 L3 进料口，不混进 wiki。

## 怎么挂新知识（≤1 次操作）
1. 判断它属于哪个节点（实体）
2. 打开对应卡片，在「待深挖」下补一条，或新建 `[[新实体]]` 卡并从 MOC/支柱链过来
3. 抓取差分来源标上 `来源: <source>`
